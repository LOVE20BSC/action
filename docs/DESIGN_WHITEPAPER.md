# LOVE20 Action 白皮书

社区投票支持一项行动后，还需要有人参与、有人确认完成情况，并把奖励分给相应的人。Action 负责把这些事情按事先约定的规则办下来。

这份白皮书面向想了解或参与行动的人。我们从实际会遇到的事情讲起：怎样加入，钱放在哪里，奖励怎么分，做不好又会怎样。

| 文档 | 主要讲什么 |
| --- | --- |
| [行动是怎样运转的](ACTION_TARGET.md) | 投票、参与和领奖怎样衔接，谁有权操作，钱由谁保管 |
| [群行动](GROUP_ACTION.md) | 大家怎样组群做事、接受资助，由谁确认结果，失职怎样扣押金 |
| [群服务](GROUP_SERVICE.md) | 群主和验证者怎样获得服务奖励，怎样把群主奖励分给协作者 |
| [流动性行动](LP.md) | 提供交易池份额怎样参与，加入早晚怎样影响奖励，什么时候能取回本金 |

建议先读《行动是怎样运转的》，再选择感兴趣的行动类型继续读。每篇都按当前已经实现的规则说明，例子中的金额和比例只是为了方便理解。

治理票怎样获得、社区代币怎样发行，以及群聊功能怎样使用，需要另行了解；这里主要讲行动中的参与和分配。
