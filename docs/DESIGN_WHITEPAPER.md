# LOVE20 Action 白皮书

大家通过参与行动、组织协作、验证成果或提供流动性，按协议规则铸造激励代币。Action 把社区投票、行动参与、结果验证和激励铸造连接起来。

这份白皮书面向想了解或参与行动的人。我们从实际会遇到的事情讲起：怎样加入，参与代币怎样存放，激励代币怎样铸造，未完成约定会怎样。

文中的“链群”指链上的社群。

| 文档 | 主要讲什么 |
| --- | --- |
| [行动是怎样运转的](ACTION_TARGET.md) | 投票、参与和铸造怎样衔接，身份有哪些权限，代币怎样存放 |
| [链群行动](GROUP_ACTION.md) | 怎样通过链群参与行动、使用资助、验证成果和铸造激励代币，失职怎样扣罚质押代币 |
| [链群服务](GROUP_SERVICE.md) | 怎样依据组织和验证成果铸造服务激励代币，以及协作者怎样参与分配 |
| [LP 行动](LP.md) | 怎样通过流动性凭证（LP token）参与，数量和时间怎样影响激励，退出时怎样取回流动性凭证 |

建议先读《行动是怎样运转的》，再选择感兴趣的行动类型继续读。每篇都按当前已经实现的规则说明，例子中的数量和比例只是为了方便理解。

治理票怎样获得、社区代币怎样发行，以及链群消息功能怎样使用，需要另行了解；这里主要讲行动中的参与和分配。
